# Getting help

1. Run `ibus-llm-assist status` and read [docs/troubleshooting.md](docs/troubleshooting.md), which follows its
   messages.
2. Search the [issues](https://github.com/maximeallanic/ibus-llm-assist/issues), open or closed.
3. Ask in [Discussions](https://github.com/maximeallanic/ibus-llm-assist/discussions), or open an issue with the
   output of `ibus-llm-assist status`, your distribution and GNOME version.

Security problems: see [SECURITY.md](SECURITY.md), not a public issue.
